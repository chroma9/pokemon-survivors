# Alternate Pokémon forms — asset and Pokédex conventions

A playable alternate form (regional, special, or event) can share its base species' National Dex number without sharing its visual identity.

## Artwork and rendering

- Place art in `public/assets/pokemon/<national-dex>/<form-key>/` (e.g. `150/shadow/`).
- Register the form in `src/data/sprites.generated.json` under `<dex>.forms.<form-key>` with accurate sheet dimensions, timings and portrait availability.
- Use `formPortraitUrl(dex, formKey)` for form-specific portraits in **every** UI location, including the roster, character details header, evolution line, and Pokédex.
- Pass the form key to `loadSpecies(dex, shiny, formKey)` and form-aware sprite lookups. Merely using `portraitUrl(dex)` or loading `dex` without a form loads the default species art.
- Reuse the National Dex number for regional forms such as Hisuian Zorua. Don't replace the original species' art.

## Pokédex identity

- The regular Pokédex tracks species by **National Dex number**, so alternate forms share the base species' progress and should not create duplicate completion-count entries.
- The in-game Pokédex can show a form selector inside the existing species entry, rather than generating another species page.
- For private or account-exclusive forms, visibility must be conditional on the owning trainer. No public form page, thumbnail, silhouette, or completion requirement.
- Public static pages generated by `src/site/pokedex.ts` must not expose private forms; this code runs at build time, not inside the authenticated app.
- A client-side trainer handle check is **not** secure authorization. For giftable/exclusive unlocks, ownership must ultimately be verified by the trainer account backend.

## Shadow Mewtwo precedent

Shadow Mewtwo is a separate playable Legendary ID (`shadowMewtwo`) sharing base dex #150 with Mewtwo, using artwork from `150/shadow/`. It is not a regular Legendary for Arceus unlock requirements, has no shiny form, and must not appear to unentitled players.

Future Hisuian Zorua and other regional Pokémon should follow the same form-aware rendering conventions, but use their own legitimate unlock rules.
